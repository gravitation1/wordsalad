# Word-list licenses

The game code is licensed separately (see the repository's `LICENSE`). The
word lists below are derived data files; each carries its own license,
scoped to that file. None of these licenses extends to the game code:
distributing code alongside independently licensed data files is what the
GPL itself calls "mere aggregation" (GPLv2 §2; GPLv3 §5).

Each list was produced by filtering its source lexicon to common words
(an OpenSubtitles-derived frequency floor via
[FrequencyWords](https://github.com/hermitdave/FrequencyWords), MIT),
removing group-targeting slurs, and normalizing spelling forms. The lists
are free to copy and modify under their respective licenses.
